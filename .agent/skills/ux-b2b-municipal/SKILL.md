# UX B2B Municipal

Directrices de diseño, usabilidad y formalidad técnica para adquisiciones de seguridad pública.

## Principios Clave
1. **Tono institucional:** Usar paleta cromática sobria (#0A192F Azul Policía, #FFD700 Dorado, fondos limpios #F8FAFC) y tipografía legible.
2. **Claridad presupuestal:** Los directores de compras necesitan ver el desglose claro de Subtotal, IVA (16%) y Total en todo momento.
3. **Matriz de tallas masiva:** Facilitar la selección rápida de múltiples tallas para una misma corporación (ej. 20 M, 30 L, 15 XL) sin tener que repetir todo el proceso.
4. **Datos del solicitante completos:** Capturar municipio, área requirente, titular y datos de contacto oficiales.

## Checklist de UX/UI
- [ ] Validar campos obligatorios con retroalimentación visual amigable (bordes rojos, foco automático, mensajes claros).
- [ ] Asegurar que el modal de cotización sea responsive en pantallas móviles y de escritorio.
- [ ] Respetar términos técnicos del sector (Partida presupuestal, Calibre, Confección ripstop, etc.).
- [ ] Evitar términos informales de e-commerce como "Pagar ahora" o "Comprar ya"; preferir "Generar Cotización" o "Requisición Formal".
- [ ] Probar contraste y legibilidad según pautas WCAG AA.
